### Бронирование кабинета

Простая система для бронирования офисных кабинетов через командную строку.

#### Установка и настройка

1.  ```  
    git clone 
    ```

2. ```
   python -m venv venv
   venv\Scripts\activate  # на Windows
   ```

3. ```
   python create_db.py
   ```

##### Проверка доступности кабинета
```
python cli.py check <номер_кабинета> "<время_начала>" "<время_конца>"
```
Пример:
```
python cli.py check 1 "2026-01-15 09:00" "2026-01-15 10:00"
```

##### Добавление бронирования
```
python cli.py add "<ФИО>" "<телефон>" "<время_начала>" "<время_конца>" <номер_кабинета>
```
Пример:
```
python cli.py add "Иванов Иван Иванович" "+7-123-456-7890" "2026-01-15 09:00" "2026-01-15 10:00" 1
```

#### Формат времени
Используйте формат: `YYYY-MM-DD HH:MM` (например, "2026-01-15 09:00").

#### Примечания
- Кабинеты: 1-5.
- Бронирование не допускает пересечения по времени для одного кабинета.
- Логи выводятся в консоль.
