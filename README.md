### Бронирование кабинета

Простая система для бронирования офисных кабинетов через командную строку.

#### Установка и настройка

 ```  
    git clone https://github.com/MrKarkk/office-booking.git
```

```
   python create_db.py
```

##### Проверка доступности кабинета
```
python cli.py check <номер_кабинета> "<время_начала>" "<время_конца>"
```
Пример:
```
python cli.py check 1 "2026-01-15 09:00" "2026-01-15 10:00"
```

##### Добавление бронирования
```
python cli.py add "<ФИО>" "<телефон>" "<email>" "<время_начала>" "<время_конца>" <номер_кабинета>
```
Пример:
```
python cli.py add "Aziz" "+8080" "aziz@gmial.com" "2026-01-15 09:00" "2026-01-15 10:00" 1
```
